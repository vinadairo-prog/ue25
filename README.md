
# Übung 25 - Exception Handling


## 1. Aufgabe


Erweitern Sie die zweite Aufgabe aus Übung 23 (`MediaLibrary`) um Exceptions: Schreiben Sie eine Klasse `MediaLibraryException`, welche von der `Exception`-Klasse erbt. Erzeugen Sie einen Konstruktor, welcher einen String (dient als Fehlermeldung) als Parameter hat und den Konstruktor der `Exception`-Klasse verwendet. Werfen Sie diese Exception nun überall, wo Fehler auftreten können. Behandeln Sie die Exceptions geeignet.
